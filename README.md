# jcrendon.github.io

Personal portfolio of Juan Camilo Rendón: AI applied to biomedical engineering (medical imaging, clinical decision support, biosignals, wearable motion analysis).

Live site: https://jcrendona.github.io/jcrendon.github.io/

| Path | Content |
|---|---|
| `index.html` | Home: profile, filterable projects, experience, skills, contact |
| `projects/*.html` | Case studies (problem, contribution, data and methods, results, limitations) |
| `assets/images/projects/` | Figures generated by `tools/build_figures.py` in [biomedical-ai-portfolio](https://github.com/jcrendona/biomedical-ai-portfolio) |
| `assets/documents/Juan_Camilo_Rendon_CV.pdf` | CV, built from `cv/cv.html` |

Rebuild the CV PDF (macOS):

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --no-pdf-header-footer \
  --print-to-pdf="$PWD/assets/documents/Juan_Camilo_Rendon_CV.pdf" "file://$PWD/cv/cv.html"
```

Plain HTML/CSS/JS with no build step, served by GitHub Pages.
